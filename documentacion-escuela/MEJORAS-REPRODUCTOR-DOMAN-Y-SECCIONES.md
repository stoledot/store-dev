# Ajustes de slides Doman y secciones del curso

- El escenario Doman se limita a la altura disponible de la ventana; el texto
  vuelve a ajustarse al cambiar el tamaño de pantalla y puede partir palabras
  largas para evitar recortes horizontales.
- La vista de `/escuela/mi-escuela` agrupa las lecciones XML bajo su sección y
  conserva el orden del temario. Los cursos sin secciones XML se muestran en un
  grupo llamado “Lecciones del curso”.

No requiere migración de base de datos.
