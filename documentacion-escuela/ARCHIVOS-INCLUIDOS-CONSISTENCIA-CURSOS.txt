Instalación resumida:
1. Haz copia de seguridad de D1 y del bucket privado FILES.
2. Extrae el ZIP sobre la raíz del proyecto y conserva las rutas.
3. Ejecuta npm run db:migrate en local.
4. Ejecuta npm run check, npm test y npm run build.
5. Prueba con un curso y un alumno de prueba antes de aplicar npm run db:migrate:remote.

Regla de contenido:
- Conserva el mismo id TeX cuando sea la misma actividad lógica.
- Usa un id nuevo para una actividad nueva o un reemplazo sustancial.
- Las actividades retiradas se archivan; no se borran entregas ni avance.
